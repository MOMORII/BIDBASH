## Repository Information
This repository contains the development and supporting documentation for BIDBASH, a final-year undergraduate project focused on the design, implementation, and evaluation of a gamified online auction system (OAS). It includes artefacts spanning the full development lifecycle: research and analysis, system design and planning, prototype implementation, and evaluation outputs. All materials correspond to the accompanying dissertation.

## Project Overview
The following information will serve to summarise project information in accordance with the assignment brief and the group project requirements outlined in the 'Final Year Project' module guideline PDFs.

### Project Summary
BIDBASH is a web-based, user-facing auction platform designed to enhance traditional bidding systems through gamification and user-centred design (UCD) principles. The project investigates whether integrating engagement-driven mechanics (e.g. rewards, progression systems, and feedback loops) can improve usability, accessibility, and user engagement, particularly for novice or first-time users of auction platforms. Rather than functioning solely as a development exercise, BIDBASH is positioned as a proof-of-concept system used to empirically evaluate the effectiveness of gamified interaction models within an auction context.

### Core Features
1. Real-time bidding interface with countdown-based auctions
2. Gamified interaction elements (e.g. points, levels, rewards)
3. Visual feedback systems to enhance user engagement
4. Simplified onboarding and user-friendly navigation
5. Profile-based progression and activity tracking
6. Notification and feedback mechanisms for bid activity
...

### Key Architectural Characteristics
- Web-based application for cross-platform accessibility
- Component-based front-end design (e.g. reusable UI elements)
- Event-driven backend to support real-time bidding interactions
- Separation of concerns between interface, logic, and data layers
- Scalable structure suitable for proof-of-concept extension

### Security and Data Considerations
- Minimal collection of personal data for testing and evaluation
- Secure handling of any user input during prototype interaction
- No real financial transactions (simulation-only environment)
- Transparency in system behaviour to support user trust

### Non-Functional Requirements 
- Usability: intuitive interface for novice users
- Performance: responsive interaction during bidding events
- Accessibility: clear navigation and readable UI design
- Scalability: structured to support future feature expansion

### Chosen Methodology
Development follows a User-Centred Design (UCD) approach, supported by:

- iterative prototyping
- user feedback collection (questionnaires, interviews, usability testing)
- continuous refinement based on evaluation outcomes

An Agile-inspired workflow is used to support incremental development and flexibility throughout the project lifecycle.

### Development Approach
- Iterative design and implementation aligned with UCD principles
- Task tracking and version control managed via GitHub
- Regular updates and refinements based on research findings and user feedback
- Emphasis on balancing functional reliability with experiential engagement
  
## Conclusion
BIDBASH aims to bridge the gap between transaction-focused auction systems and engagement-driven user experiences. By combining established auction mechanics with gamification strategies, the project explores how interactive design can make bidding more accessible, enjoyable, and effective for a wider audience.
